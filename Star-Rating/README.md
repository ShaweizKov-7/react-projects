# Star Rating

An interactive star rating component built with React.

## Features

- Select a rating by clicking a star
- Displays the selected rating
- Interactive hover/click behavior
- Reusable component structure

## Concepts Practiced

- React `useState`
- Event handling
- Conditional rendering
- Array mapping
- Component design

## Technologies

- React
- JavaScript
- CSS
- Vite
