# Load More Products

A dynamic product list built with React that allows users to load additional products as needed.

## Features

- Displays products dynamically
- Loads additional products on button click
- Fetches product data from an API
- Updates the product list without reloading the page
- Handles loading states

## Concepts Practiced

- React components
- Props
- `useState`
- `useEffect`
- API requests
- `fetch`
- Array mapping
- Conditional rendering
- Event handling
- State updates

## Technologies

- React
- JavaScript
- CSS
- Vite
