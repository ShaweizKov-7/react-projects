# Light & Dark Theme Mode

A responsive light and dark theme switcher built with React.

## Features

- Toggle between light and dark themes
- Uses React state to manage the current theme
- Uses CSS variables for theme styling
- Theme preference is stored in localStorage
- Responsive UI

## Concepts Practiced

- React `useState`
- React `useEffect`
- Custom hooks
- Local storage
- Conditional rendering
- CSS variables
- Event handling

## Technologies

- React
- JavaScript
- CSS
- Vite
