# Search Auto Complete

A simple search auto-complete application built with React that provides suggestions as the user types.

## Features

- Searches through a list of items
- Displays matching suggestions while typing
- Updates suggestions dynamically
- Allows users to select a suggestion
- Handles empty search input
- Provides a simple and responsive interface

## Concepts Practiced

- React components
- Props
- `useState`
- Event handling
- Input handling
- Array filtering
- Array mapping
- Conditional rendering
- String methods
- State updates

## Technologies

- React
- JavaScript
- CSS
- Vite
