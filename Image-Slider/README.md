# Image Slider

A simple image slider built with React that allows users to navigate through a collection of images.

## Features

- Displays images dynamically
- Navigate between images
- Previous and next controls
- Handles the beginning and end of the image collection
- Updates the displayed image based on user interaction

## Concepts Practiced

- React components
- Props
- `useState`
- Conditional rendering
- Array mapping
- Array indexing
- Event handling
- State updates

## Technologies

- React
- JavaScript
- CSS
- Vite
