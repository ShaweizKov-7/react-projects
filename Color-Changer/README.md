# Random Color Generator

A simple random color generator built with React that generates a new color when the user clicks a button.

## Features

- Generates random colors dynamically
- Displays the generated color
- Updates the background color instantly
- Supports different color formats
- Generates a new color on button click

## Concepts Practiced

- React components
- `useState`
- Event handling
- Conditional rendering
- Random number generation
- State updates
- Dynamic styling
- Array mapping

## Technologies

- React
- JavaScript
- CSS
- Vite
