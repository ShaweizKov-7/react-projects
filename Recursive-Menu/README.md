# Recursive Tree Menu

A dynamic nested menu built with React using recursive components.

## Features

- Displays nested menu items dynamically
- Supports multiple levels of nesting
- Expand/collapse menu items
- Handles dynamically structured data

## Concepts Practiced

- React components
- Props
- `useState`
- Conditional rendering
- Array mapping
- Recursive components
- Nested data structures
- Event handling

## Technologies

- React
- JavaScript
- CSS
- Vite
