# Accordion

A simple interactive accordion built with React that allows users to expand and collapse content sections.

## Features

- Displays multiple accordion items dynamically
- Expand and collapse individual items
- Shows and hides content based on user interaction
- Handles multiple accordion items

## Concepts Practiced

- React components
- Props
- `useState`
- Conditional rendering
- Array mapping
- Event handling
- State management
- Dynamic rendering

## Technologies

- React
- JavaScript
- CSS
- Vite
