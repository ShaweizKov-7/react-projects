# Tabs

A simple tab navigation component built with React that allows users to switch between different sections of content.

## Features

- Displays multiple tabs dynamically
- Switches content based on the selected tab
- Highlights the active tab
- Handles user interaction
- Renders content dynamically

## Concepts Practiced

- React components
- Props
- `useState`
- Conditional rendering
- Array mapping
- Event handling
- State management
- Dynamic rendering

## Technologies

- React
- JavaScript
- CSS
- Vite
